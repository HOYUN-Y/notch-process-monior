## 인터페이스 미감 정돈 (feat/navy-slate-interface)

방향: 기존 navy/slate 안에서 정돈한다. 평탄한 목록을 유지하고, 실제 항목 이름과 앱 아이콘이 중심이 되게 한다. 새 기능, 백엔드(AX·권한·종료 안전 로직) 변경은 하지 않는다.

- [x] 테마: 표면 3단계(배경·패널·선택/입력), 얇은 경계선, 텍스트 3단계, 강조색은 선택 행과 화면당 주 동작에만
- [x] 목록 행: 기본 행의 강조를 낮추고 선택·포커스·마우스 오버를 명확하게 표시. "메뉴 열기"는 선택 행에서만 강조. 앱 열기/앱 종료는 접근성 이름이 있는 행 보조 메뉴(⋯)와 우클릭 메뉴로 이동. 넓은 창에서 이름과 동작 사이가 벌어지지 않게 정리
- [x] 상태 문구: 1~2줄로 줄이되 결과(응답 없음·미확인·실패·종료 요청)는 화면에 그대로 표시
- [x] 하단: 같은 앱·같은 원인의 조회 실패를 개수로 묶고 상세 목록 경로 제공(실패를 숨기지 않음)
- [x] 권한 화면: 처음 할 일(요청 → 확인)과 추가 복구 정보를 나누고, 기본 크기에서 스크롤 없이 주요 버튼이 보이게
- [x] 기본 창 크기 900×640, 최소 560×420 유지
- [x] 검증(구현자): `swift test` 9개 통과, 디버그 빌드 화면 확인(다크·라이트, 목록·권한·빈 검색·긴 문구·실패 상세·⋯ 메뉴·종료 확인, 기본·최소 크기). 메뉴 실행·종료는 저장소 fixture만 대상
- [x] 독립 시각 검수 PASS(수정 1회 후): 기준 9개(C1~C5, W1~W4) 모두 8점, B01·B02 해결, 미해결 P0/P1/P2 없음. W2는 컨텍스트 메뉴 키로 키보드 작업 확인, W3는 합성 30그룹 QA 실행본으로 스크롤 확인(실제 OS 오류·TCC 증거 아님)
- [x] 독립 검수 통과 후 canonical 앱 번들 1회 생성(서명·plist·셸 구문 검사 통과)
- [x] 새 canonical release 번들 실행·권한 안내 화면 최종 확인(독립 검수자): 제목·테마·실제 경로·재확인 시각 갱신·Finder 선택·서명·검수 소스 일치 확인
- [ ] 새 ad-hoc 서명에 대한 손쉬운 사용 재등록과 앱 자체 권한으로 목록 진입 확인(사용자 조작 필요, 미완료)
